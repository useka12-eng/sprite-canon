# PC 부품 최저가 모니터

다나와 가격비교 페이지에서 아래 부품의 최저가를 조회하고, `baseline.json`의 기준가보다 내려가면 알린다.

| 부품 | 추적 대상 |
| --- | --- |
| CPU | AMD 라이젠7 7800X3D (정품, 멀티팩 정품) |
| RAM | KingBank DDR5 32GB(16Gx2) 화이트 (6000 CL30, 6400 CL32) |
| GPU | 라데온 RX 9070 XT 16GB 신품 전 모델 (중고 제외) |
| 케이스 | DEEPCOOL CH160 PLUS (화이트, 블랙) |
| 파워 | SFX 화이트 750W 이상 80PLUS 골드 (리안리 SP750 V2 / SP850 V2, FSP DAGGER PRO 850W) |

## 최저가 기준

상품 페이지에서 관측되는 가격을 모두 모은다.

- 다나와 최저가, 쇼핑몰 판매가
- 카드결제 혜택가 (특정 카드 결제 시)
- N+멤버십 혜택가 (네이버 적립 예정 포인트 차감 후 가격)
- 현금 최저가 (현금결제 전용)

부품마다 기준가를 두 개 둔다. 둘 중 하나라도 내려가면 하락으로 본다.

- `all`: 현금가를 포함한 전체 최저
- `card`: 현금가를 제외한 최저

다나와 최저가의 60% 미만인 값은 오등록으로 보고 버린다. 배송비는 페이지에 표시된 경우 조건란에 함께 적는다.

## 사용법

```
python3 monitor.py            # 조회 + 판정 (기준가 변경 없음)
python3 monitor.py --update   # 하락한 항목의 기준가를 새 최저가로 갱신
python3 monitor.py --init     # 기준가를 현재가로 다시 만든다
```

종료 코드: `0` 하락 없음, `10` 하락 있음, `2` 조회 실패. 표준 라이브러리와 `curl`만 쓴다.

추적 상품을 바꾸려면 `parts.json`의 `pcode`(다나와 상품 코드)를 고친 뒤 `--init`을 다시 실행한다.

## 자동 실행

Claude Code 예약 작업(`PC부품최저가 | ...`)이 6시간마다 새 세션에서 `pm.py`를 실행한다.

- `pm.py`는 `monitor.py`의 단일 파일 축약판이다. 예약 작업 프롬프트에 그대로 내장되어 있어 저장소 접근 없이 동작한다. 추적 상품을 바꾸면 두 곳(이 파일과 예약 작업 프롬프트)을 함께 고친다.
- 기준가는 예약 작업 이름의 `|` 뒤에 `부품ID 전체최저/카드최저` 형식으로 저장된다. 하락이 감지되면 에이전트가 이름을 새 최저가로 바꾸고 푸시 알림을 보낸다.
- 실행 환경은 `prod.danawa.com` 접근이 허용된 클라우드 환경(`sprite-canon-price-monitor`)이다.

```
python3 pm.py "cpu 335200/357580 ram 649340/649340 gpu 1187000/1349100 case 78120/78120 psu 169000/188100"
```
